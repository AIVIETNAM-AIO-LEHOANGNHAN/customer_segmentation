## BUG-007 (Minor) — Sắp xếp theo CustomerID là sắp xếp chuỗi, không phải sắp xếp số

**Vị trí:** `src/visualization/rfm_dashboard.py`, hàm `sort_rfm_table` (dòng 102-105)

```python
def sort_rfm_table(df: pd.DataFrame, sort_column: str, ascending: bool) -> pd.DataFrame:
    if sort_column not in df.columns:
        return df
    return df.sort_values(sort_column, ascending=ascending, kind="mergesort")
```

`CustomerID` được `_validate_rfm_frame()` ép về kiểu `str` (đúng đặc tả T06). Khi người dùng chọn "Sort by: CustomerID", `sort_values()` sắp xếp cột này theo **thứ tự từ điển (lexicographic)**, không phải theo giá trị số.

**Hiện tại không lộ ra** vì toàn bộ `CustomerID` trong Online Retail II đều có đúng 5 chữ số (12346–18287), nên sắp chuỗi và sắp số cho cùng kết quả. QA đã dựng lại bằng dữ liệu tối giản:

```python
mixed = pd.DataFrame({"CustomerID": ["9999", "12347", "12348", "555"], ...})
sort_rfm_table(mixed, "CustomerID", ascending=True)["CustomerID"].tolist()
# Thực tế : ['12347', '12348', '555', '9999']   <- sắp theo CHUỖI
# Đúng ra : ['555', '9999', '12347', '12348']   <- sắp theo SỐ
```

**Vì sao đáng ghi nhận dù chưa gây hại:** đây đúng kiểu lỗi "ẩn mình chờ dữ liệu mới" — sẽ lộ ra ngay khi hệ thống nhận một bộ dữ liệu có mã khách hàng độ dài khác nhau (rất có thể xảy ra nếu Task 3 sau này nhận thêm nguồn dữ liệu khác Online Retail II).

**Đề xuất fix:**

```python
def sort_rfm_table(df, sort_column, ascending):
    if sort_column not in df.columns:
        return df
    if sort_column == ID_COLUMN:
        key = pd.to_numeric(df[sort_column], errors="coerce")
        return df.assign(_sort_key=key).sort_values(
            "_sort_key", ascending=ascending, kind="mergesort"
        ).drop(columns="_sort_key")
    return df.sort_values(sort_column, ascending=ascending, kind="mergesort")
```

**Test tương ứng:** `test_group4_sort_by_customer_id_is_numeric_not_lexicographic`

## BUG-008 (Minor) — Boxplot vỡ khi xuất dữ liệu đầy đủ ngoài Streamlit

**Vị trí:** `src/visualization/rfm_dashboard.py`, hàm `make_boxplot` (dòng 153-167)

```python
def make_boxplot(df: pd.DataFrame) -> alt.Chart:
    long_df = df[FEATURE_COLUMNS].melt(var_name="Feature", value_name="Value")
    return alt.Chart(long_df).mark_boxplot(...)...
```

`melt()` biến 4.324 dòng × 3 cột thành 12.972 dòng "dài". Khi gọi `.to_dict()` (cách Altair chuẩn để xuất spec/JSON, dùng khi lưu ảnh tĩnh, nhúng vào notebook, hay so sánh trong test):

```
altair.utils.data.MaxRowsError: The number of rows in your dataset (12972)
is greater than the maximum allowed (5000).
```

**Trên UI thật của dashboard KHÔNG vỡ** — QA đã kiểm chứng kỹ bằng `AppTest`, mở tab Boxplot với đầy đủ 4.324 khách hàng, không phát sinh exception. Nguyên nhân: `st.altair_chart()` không đi qua con đường `to_dict()` mặc định của Altair, mà tự serialize dữ liệu sang định dạng Arrow nhị phân rồi gửi qua kênh riêng (`datasets` trong protobuf) — né được giới hạn 5.000 dòng vốn chỉ áp dụng khi nhúng dữ liệu trực tiếp vào JSON.

**Nhưng đây vẫn là một cái bẫy thật** cho bất kỳ ai tái sử dụng `make_boxplot()` bên ngoài ngữ cảnh Streamlit — ví dụ script xuất ảnh PNG cho báo cáo (`chart.save("boxplot.png")` cũng đi qua `to_dict()`), notebook phân tích, hay ai đó viết test so sánh spec bằng `.to_dict()`.

**Đề xuất fix:** bật `vegafusion` transformer (nới giới hạn hàng bằng cách tiền xử lý trong Python trước khi xuất) hoặc nâng giới hạn tường minh:

```python
import altair as alt
alt.data_transformers.enable("vegafusion")   # hoặc alt.data_transformers.disable_max_rows()
```

**Test tương ứng:** `test_group5_boxplot_spec_is_exportable_for_large_dataset`

## BUG-010 (Minor) — Boxplot gộp 3 đặc trưng lên chung một trục, chênh lệch thang đo quá lớn

**Vị trí:** `make_boxplot()`, cùng chỗ với BUG-008

Recency (0–373), Frequency (1–203) và Monetary (2,9–278.742) bị vẽ trên **cùng một trục Y tuyến tính** ở view "RFM original". Tỷ lệ giữa max Monetary và max Recency là **747 lần**. **Đề xuất:** tách 3 boxplot riêng theo từng đặc trưng (giống cách `_render_histograms()` đã làm), hoặc dùng `resolve_scale(y="independent")` nếu vẫn muốn gộp trong một khối:

```python
alt.Chart(long_df).mark_boxplot(...).encode(...).facet(
    column="Feature:N"
).resolve_scale(y="independent")
```
